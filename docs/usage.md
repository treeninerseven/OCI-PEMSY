# PEMSY 操作说明

本项目面向课程 PEMSY 电路板、RP2040 Pico、16×2 字符 LCD 和 RFM69 射频模块。主机测试和固件编译可以验证软件行为；实际 LCD、旋钮、无线距离、频率偏差和 mioty 基站接收仍须用实物验收。

## 日常操作

开机进入收件箱。没有消息时显示本机地址；收到消息后显示发件人地址和最新一条消息。旋转旋钮依次切换收件箱、温度、对比度三个页面。

| 操作场景 | 操作 | 结果 |
| --- | --- | --- |
| 收件箱 | 短按或按住 3 秒 | 选择收件人 |
| 温度或未编辑的对比度页 | 按住 3 秒 | 选择收件人 |
| 收件人选择 | 旋转 | 在 1–255 中选择目标，自动跳过本机地址 |
| 收件人选择 | 短按 | 开始新的文本输入 |
| 收件人选择 | 按住 3 秒 | 返回收件箱 |
| 文本输入 | 旋转 | 更改当前字符，范围为可打印 ASCII，包括空格、英文字母、数字及标点 |
| 文本输入 | 短按 | 确认当前字符，继续下一个字符 |
| 文本输入 | 按住 3 秒 | 保存文本，进入发送确认 |
| 发送确认 | 短按 | 发送；发送期间等待驱动结果 |
| 发送确认 | 按住 3 秒 | 取消发送，返回收件箱 |
| 温度 | 短按 | 请求 mioty 温度上报 |
| 对比度 | 短按 | 进入或退出调节 |
| 对比度调节 | 旋转 | 调整 PWM 占空比，范围为 0–10%，默认 1.5% |
| 对比度调节 | 按住 3 秒 | 退出调节并返回收件箱 |

输入最多 16 个字符。确认第 16 个字符后自动进入发送确认。开始输入时默认字符是 `A`；每次短按后，下一个预览也显示 `A`。如果短按后直接长按结束输入，不会自动追加这个新预览；旋转过的新预览会在长按时保存。这样输入完最后一个字后既可以短按再长按，也可以直接长按。

地址 **255** 表示广播；界面会显示 `To ALL (255)`，确认时显示 `Broadcast? Click`。单播和广播都只面向使用相同射频组参数的设备。广播源地址不能为 255；每台设备必须使用不同的本机地址 1–254。

`TX sent` 仅说明本机射频发送完成，没有对端送达确认。`TX failed: retry` 表示失败，文本仍保留在发送确认页，短按可重试。进入新的文本输入会清空原草稿。

## 温度和 mioty

温度页显示 RP2040 内部温度传感器的估算值，单位 °C，每秒更新。它反映芯片温度，不是经过校准的环境温度计。超出软件接受范围 −50 至 150°C 时，显示不可用并拒绝上报。

默认固件关闭 mioty。启用需要填写本地私有端点配置，确保基站已注册对应身份，然后以 `PEMSY_ENABLE_MIOTY=ON` 重新编译。缺少配置、持久化计数器故障、对讲发送占用射频或未满足 60 秒上报间隔时，请求会失败；USB 日志可帮助判断原因。

mioty 与对讲共用射频模块。上报期间暂停对讲接收；旋钮、温度采样与 LCD 仍在主核工作。上报结束后程序重新初始化对讲接收。`mioty TX sent` 也不是基站接收确认，应在基站侧检查数据。上报工作核超过 60 秒仍未返回时，设备会显示超时并重启。

## 重启和故障

- 文本草稿、收件箱和对比度设置保存在 RAM；断电或复位后清空/恢复默认。收件箱只保留最新一条消息，不提供历史记录或字符删除编辑。
- mioty 计数器保存在闪存最后 8 KiB，按 256 个数预留区间。重启时跳过上次区间，避免重复使用已发计数器。正常固件构建保留该区域。
- 全片擦除、换板或恢复旧闪存镜像可能使计数器倒退。继续使用同一身份前，应重新配置基站和端点状态；不要把恢复旧镜像当作正常计数器重置方式。
- `Radio offline` 表示射频初始化或恢复失败，程序约每 5 秒重试。检查模块型号、供电、SPI、DIO0 连接及射频配置。
- 收到超长、空文本或不可打印字符的报文会被丢弃；接收消息不会打断正在输入的草稿。

## 无硬件体验

在主机测试构建后运行 `build-host/pemsy_simulator`。此工具执行真实应用状态机，但无线发送和温度数据来自模拟，不会接触硬件。

| 命令 | 含义 |
| --- | --- |
| `+` / `-` | 旋钮正转 / 反转一格 |
| `n 7` | 正转七格；可输入负数 |
| `c` | 短按 |
| `h` | 按住 3 秒 |
| `t 2350` | 设置温度为 23.50°C |
| `r 2 HELLO` | 模拟收到来自地址 2 的 HELLO |
| `f` | 让下一次模拟发送失败 |
| `q` | 退出 |

例如依次输入 `h`、`c`、`n 7`、`c`、`n 8`、`h`、`c`，即可向默认地址 2 模拟发送 `HI`。在收件人选择页，从默认地址 2 反转一格会选中广播地址 255。
